# Recupera-oL-gicadePrograma-o
Repositório dedicado a um sistema de cadastro de medicamentos para a realização da recuperação do 2° trimestre.
Para executá-lo use "python main.py" no terminal para rodar o programa.

Funcionalidades principais: Cadastro de medicamentos, listagem dos medicamentos cadastrados, busca por nome e salvamento automático dos dados.
Requisitos técnicos aplicados: Usei funções para organizar o código (cadastrar_medicamento, listar_medicamentos e buscar_medicamento), estruturas condicionais e de repetição no menu e nas validações, listas e dicionários para armazenar os dados e manipulação de arquivos CSV nas funções carregar_medicamentos e salvar_medicamentos.
